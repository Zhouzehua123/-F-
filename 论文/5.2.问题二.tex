\subsubsection{具体分析}

问题二需要回答：在参数规模与训练数据量之外，数据质量和领域配比如何影响验证损失，以及质量提升能够在何种条件下替代规模扩张。难点在于附件 A 与 B 并非同一组联合实验，质量评分与配比效应不能未经校准便直接叠加。本文以经典标度律描述规模效应，在附件 B 内比较质量项的候选形式，再利用问题一输出讨论领域效应及其迁移条件。

具体而言，先在 Pythia 训练轨迹上拟合经典关系，并以较小模型拟合、较大模型留出的方式检验族内迁移表现；随后核对半合成质量字段的方向，比较四类广义模型；最后在既定模型下计算局部弹性与质量--参数等效关系，结合多源检验界定结论的适用范围。领域分析沿用问题一的配比系数，区分效应模式相似性与尚待验证的互补增益。

\subsubsection{模型准备}

\textbf{1.数据组织与变量口径}

经典标度律以 B1 为主拟合数据。该表包含 8 个 Pythia 模型的训练轨迹，每个模型具有 147 个检查点，共 1{,}176 条记录\cite{biderman2023pythia}。质量项由 B6 半合成实验提供信息，B7 中去除与 B6 重复的记录后用于扩展检验。其余数据按用途分层：B2、B3 检查轨迹一致性，B4、B5 评价跨族及文献数据上的适用性，B8 用于口径诊断，B10 用于大规模估算对照。B9 与 B10 的元数据匹配尚需补充，不能将单独读取 B9 视为已完成联合分析。

记参数量为 $N$，训练数据量为 $D$，验证集交叉熵损失为 $L$。本节计算中，$N$ 以十亿个参数为单位，$D$ 以十亿 tokens 为单位，质量变量记为 $Q$。将参数传入问题三的算力公式时，须恢复参数个数与 token 数的实际单位。拟合直接针对原函数进行，以保留不可约损失项 $E$；因此，参数估计不依赖忽略常数项的双对数线性化。

\subsubsection{模型建立}

\textbf{1.经典标度律}

以 Chinchilla 标度律为基础\cite{hoffmann2022chinchilla}，验证损失 $L$ 满足：
\begin{equation}
    L(N,D) = E + \frac{A}{N^{\alpha}} + \frac{B}{D^{\beta}}
\end{equation}
其中，$E$ 表示 $N,D\to\infty$ 时模型给出的损失极限；$A$、$B$ 为尺度系数，$\alpha$、$\beta$ 为衰减指数，分别共同决定参数规模与数据规模的收益变化。该模型将数据质量固定在参考水平。

\textbf{2.质量缺口修正}

将质量项以“质量缺口”形式引入，得到广义标度律：
\begin{equation}
    L(N,D,Q) = E + \frac{A}{N^{\alpha}} + \frac{B}{D^{\beta}} + C\,(1-Q)^{\gamma},
    \qquad C>0,\ \gamma>0
\end{equation}
本文采用题目允许的参考归一化约定：$Q=1$ 时质量缺口项消失，模型在函数形式上退化为经典标度律。该约定不意味着 Pythia 语料已达到客观意义上的完美质量，重新联合估计后的参数也不必与经典拟合相同。在此模型假设下，固定质量对应的渐近损失为：
\begin{equation}
    \lim_{N,D\to\infty} L(N,D,Q) = E + C\,(1-Q)^{\gamma} \;\ge\; E
\end{equation}
因此，在固定 $Q$ 的模型情景内，仅增加 $N$、$D$ 不能消除质量缺口项。这是所选函数形式的条件性推论，尚不能视为对真实大模型极限的实证证明。质量项非负，使该模型的渐近下限不低于 $E$。

\textbf{3.边际效用与弹性}

在参考点 $(N_0,D_0,Q_0)$ 处，各因素的边际效用为：
\begin{equation}
    \frac{\partial L}{\partial N} = -\alpha A N^{-\alpha-1},\quad
    \frac{\partial L}{\partial D} = -\beta B D^{-\beta-1},\quad
    \frac{\partial L}{\partial Q} = -\gamma C (1-Q)^{\gamma-1}
\end{equation}
对应弹性为：
\begin{equation}
    \varepsilon_N = \frac{\partial L}{\partial N}\frac{N_0}{L_0},\qquad
    \varepsilon_D = \frac{\partial L}{\partial D}\frac{D_0}{L_0},\qquad
    \varepsilon_Q = \frac{\partial L}{\partial Q}\frac{Q_0}{L_0}
\end{equation}

\textbf{4.质量提升与参数扩张的局部等效关系}

在固定 $D$ 和配比的条件下，分别考察从同一参考点出发的微小质量提升与参数扩张。定义 $R_{NQ}$ 为两种方案产生相同一阶损失降幅时的正向等效增量比：
\begin{equation}
    \left|\frac{\partial L}{\partial Q}\right|\mathrm dQ = \left|\frac{\partial L}{\partial N}\right|\mathrm dN
    \quad\Longrightarrow\quad
    R_{NQ} = \frac{\mathrm dN_{\mathrm{eq}}}{\mathrm dQ} = \frac{\gamma C (1-Q)^{\gamma-1}}{\alpha A N^{-\alpha-1}}
    = \frac{\gamma C}{\alpha A}\,(1-Q)^{\gamma-1}N^{\alpha+1}
\end{equation}
需注意，正向等效增量比与等损失曲线斜率不同：沿同一条等损失曲线有 $\mathrm dN/\mathrm dQ=-R_{NQ}$，即提高质量允许减少参数。固定 $Q$ 时，$R_{NQ}$ 随 $N^{\alpha+1}$ 增长，反映参数扩张的边际收益递减；但是否更节约算力，还需结合问题三的质量处理成本判断，不能仅凭替代率作成本优劣结论。

\textbf{5.领域效应的相似性}

线性混合模型下，两个训练域 $i$、$j$ 对 13 个验证域损失的效应向量分别为 $\bm a_i,\bm a_j$。采用中心化后的余弦相似度描述两域的相对效应模式：
\begin{equation}
    s_{ij} = \frac{\langle \bm a_i-\bar{\bm a},\ \bm a_j-\bar{\bm a}\rangle}{\|\bm a_i-\bar{\bm a}\|\,\|\bm a_j-\bar{\bm a}\|}
\end{equation}
其中 $\bar{\bm a}$ 为 17 个域的平均效应向量。$s_{ij}\to1$ 表示两域在验证任务上的相对效应模式趋同；$s_{ij}\to-1$ 表示效应模式相反，可用于识别任务间的收益权衡。余弦相似度不包含效应幅值，不能单独证明等量替代；负相似度也不能证明联合使用具有增益。当前线性配比模型没有交互项，因此本指标仅作领域效应结构描述，不作为严格互补性的判据。

当前估计 $\gamma=0.9779<1$，故 $|\partial L/\partial Q|$ 在 $Q<1$ 内随质量缓慢增加，并在 $Q\to1^-$ 时发散。图\ref{fig:p2_margin}仅绘制至 $Q=0.99$，不把边界奇点替换为有限值。这一边界行为属于现有函数形式的局限，不能据此宣称完美质量附近具有可实现的无限收益。图\ref{fig:p2_subst}给出固定 $D$ 下的等损失情景，其曲线并非指数函数；超出主拟合规模的部分仅反映模型外推，不应作为可实现配置的依据。

图\ref{fig:p2_dom}中，wikipedia\_en 与 pile\_cc、pubmed\_central 与 pubmed\_abstracts 的相似度分别为 $0.925$ 和 $0.903$，表明它们在 13 个验证域上的相对效应模式接近。pubmed\_central 与 enron\_emails 的相似度为 $-0.967$，表示两者的效应方向存在明显差异。上述结果可辅助描述配比调整时的任务权衡，但不能仅据此断言两域必须搭配，或证明问题一推荐配比的形成机制。

最后，现有实现从问题一的线性配比模型中计算相对参考配比的损失变化，作为拟议的配比修正项 $M(\bm p)$。问题一推荐方案对应 $M=\hat L(\bm p_{\mathrm{rec}})-\hat L(\bm p_{\mathrm{ref}})=-0.1988$；这一数值是在附件 A 的验证域加权损失口径下计算得到的。将其直接作为附件 B 标度律的水平平移，需要额外假设：配比效应的尺度可迁移，且不随 $N,D,Q$ 改变。当前分层检验并未验证这一假设，因此 $0.1988$ 不能写成所有规模下均可实现的损失改善。

本节保留原有经典标度律与加性质量缺口模型，给出局部替代关系及分层检验结果。向问题三传递参数时，应同时传递半合成质量证据、边界导数行为和跨来源配比迁移的适用限制。质量尺度对接、完整配比项及严格互补性识别仍需补充论证，现阶段不将其表述为已经完成的实证结论。
