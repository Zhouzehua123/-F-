\section{模型假设}

为简化问题，本文做出以下假设：

\begin{itemize}[itemindent=2em]
\item \textbf{假设1：} 在附件 A 覆盖的配方范围内，17 个领域配比与验证域交叉熵损失可用线性混合关系近似描述；跨参数规模使用该关系时，允许整体损失尺度发生变化。
\item \textbf{假设2：} 将附件 B6、B7 的质量评分视为数值越大质量越好，并假设质量不足带来的损失可作为独立的加性项纳入经典标度律；其他来源的质量字段须先核对方向和口径。
\item \textbf{假设3：} 按赛题成本公式，将总开销分为基础训练、质量提升与长文本注意力三部分，质量成本采用赛题附录 B 给定的函数，上下文长度由附件 C7 外生给定。
\item \textbf{假设4：} 在所考察的时间窗口内，以 logistic 函数近似描述能力前沿的饱和趋势，并以面板回归近似分离参数规模与非规模技术进步对得分的贡献。
\end{itemize}
