\subsection*{附录 B：半合成与外推数据的标注}

按数据说明要求，以下数据为非直接观测，正文中的相关结论均已限定适用范围：

\begin{itemize}[itemindent=2em]
\item \textbf{半合成数据}：B2（Cerebras 训练日志）、B6/B7/B8（NQ 质量实验）。本文在标度律拟合中仅使用 B6（主）与 B7（验证），并在 5.2 节以表格明确其“半合成”性质；B2、B8 经自洽性审计后不并入拟合。
\item \textbf{外推与估算数据}：A12--A15（10B/70B 损失外推，源自 1M/60M/1B 幂律外推）、B10（百亿参数以上损失估算）。相关结论仅用于稳健性检验，未作为观测证据。
\item \textbf{插值数据}：B3（Pythia 插值轨迹），仅用于轨迹内幂指数的交叉验证。
\item \textbf{混合口径数据}：C3（跨年评测标准不完全一致）、C5/C6（Loss 来源与验证集不完全统一）。前者的异常行已被审计剔除，后者已按可比性等级分层使用。
\end{itemize}

\subsection*{附录 D：运行环境与核心实现}

程序整理、绘图代码编写与结果核对使用 Codex 辅助，模型为 OpenAI 的 GPT-5.4（2026-03-05）及 GPT-6 系列（2026-09-03 首发）\cite{ai_codex54,ai_codex6}。文段整理与图表辅助制作使用腾讯 WorkBuddy 接入的 DeepSeek-V4-Flash（深度求索，2026-04-24 首次公开发布），排版检查使用 GLM-5.1（智谱，2026-04-07）\cite{ai_workbuddy,ai_glm}。参赛队负责核验并理解所用内容，模型选取、假设设定及结果解释由参赛队承担；运行输入、参数及输出以随文提供的源程序和结果文件为准。


程序采用 Python 3，依赖 NumPy、pandas、SciPy 与 Matplotlib；数据解压和 JSON 读取使用 Python 标准库。四问程序共同调用 求解/\allowbreak{}\_common.py，附件查找以该文件中的数据根目录为准。完整源程序保存在各问目录，下列代码仅摘录核心计算，所需导入、数据加载、全局变量和结果写出均见对应完整文件。代码行号沿用源文件，以便定位。

运行顺序为问题一、问题二、问题三；问题四单独读取附件 C，可独立运行。问题一输出质量、配比及关键量，问题二据此标定配比修正并输出广义标度律参数，问题三读取两问的共享文件。输入和输出关系见表\ref{tab:code_map}。
