\subsubsection{问题分析与模型准备}

在总算力固定时，扩大模型、增加训练数据和提高数据质量会争夺同一笔预算。更大的模型能够降低参数规模项，却提高了每个 token 的训练成本；更高的质量能够减小质量缺口，却需要处理整份训练语料。因而，问题三的关键是比较这些投入带来的损失改善与算力代价，而非分别寻找三个变量的最大值。

问题二已经给出参数量、数据量和质量与损失之间的关系。本节据此加入成本约束，考察预算增加后最优配置的变化。算力最优训练研究中的参数--数据协同配置为这一分析提供了基础\cite{hoffmann2022chinchilla}；本题进一步计入质量处理和长上下文开销，并比较不同成本设定下的选择。

\par\medskip\noindent\textbf{数据与计算口径}\par

本节直接使用问题二估计的标度律参数，取 $E=1.6558$、$A=0.3808$、$\alpha=0.3266$、$B=1.2515$、$\beta=0.2767$、$C_q=0.3544$、$\gamma=0.9779$。其中质量项系数记为 $C_q$，与算力预算 $C_{\mathrm b}$ 区分。计算成本时，$N$ 和 $D$ 分别使用参数个数与 token 数；代入标度律时换算为 $n=N/10^9$、$d=D/10^9$，结果表中的 B 均表示十亿。

质量提升从参考语料出发。设 $\bar p_k$ 为 A4 配方的平均领域占比，$Q_k$ 为问题一经 A16 映射得到的领域评分，则基线取为
\[
 Q_0=\sum_{k=1}^{17}\bar p_kQ_k=0.5510.
\]
这一加权方式与参考配方保持一致，未加权样本均值 $0.4952$ 则用于基线灵敏度对照。沿用前两问的衔接设定，将该评分代入质量标度律，并限定 $Q_0\le Q\le1$；评分的跨来源数值可比性仍属于模型假设，$Q=1$ 表示设定的参考质量上界。

基准情景采用参考配比 $M=0$、幂函数型质量成本及 $2048$ tokens 上下文。对照分析分别更换质量成本函数和上下文长度，其余条件保持一致。上下文长度由任务与架构外生给定，取附件 C7 的五个档位：2048、4096、8192、32768 和 131072 tokens。问题一的推荐配比以 $M=-0.1988$ 作补充情景，讨论其对损失水平的影响。

\subsubsection{模型建立}

\textbf{1.每个训练 token 的算力代价}\par\nopagebreak[4]
基础训练成本采用 $6ND$ 近似\cite{hoffmann2022chinchilla}，质量处理和注意力成本采用赛题给定形式\cite{data2026f}。在允许的质量范围内，三类 $g(Q)$ 均单调增加，故记 $\Delta g(Q)=g(Q)-g(Q_0)\ge0$，总成本可整理为
\begin{equation}
 C_{\mathrm{tot}}
 =6ND+D\Delta g(Q)+\eta ND L_{\mathrm{ctx}}
 =D\underbrace{\left[(6+\eta L_{\mathrm{ctx}})N+\Delta g(Q)\right]}_{\text{单位 token 的合计算力成本}},
 \qquad \eta=2\times10^{-4}.
 \label{eq:p3_cost_total}
\end{equation}
这一写法说明，增加数据量会同时增加训练、注意力与质量处理开销；提高质量虽然不改变模型参数量，却增加每个 token 的处理成本。即使质量已经达到上界，新增数据仍需支付这笔费用。

题设的三类质量成本列于表\ref{tab:p3_functions}。比较时使用增量 $\Delta g(Q)$，各函数在 $Q_0$ 处的增量成本均为零。

\textbf{2.预算约束下的配置模型}\par\nopagebreak[4]
记 $k=6+\eta L_{\mathrm{ctx}}$。给定配比和上下文长度后，以预测验证损失最小为目标，得到
\begin{equation}
 \begin{aligned}
 \min_{N,D,Q}\quad &E+A n^{-\alpha}+B d^{-\beta}+C_q(1-Q)^\gamma+M,\\
 \mathrm{s.t.}\quad&D\,[kN+\Delta g(Q)]\le C_{\mathrm b},\qquad Q_0\le Q\le1,\\
 &10^5\le N\le10^{15},\qquad 10^6\le D\le10^{16}.
 \end{aligned}
 \label{eq:p3_problem}
\end{equation}
后两项规模界限用于限定数值搜索域，并非实际语料供给上限。$M$ 为固定的配比修正项，因此改变 $M$ 只平移目标函数，不改变本模型的最优配置。

固定质量且规模界限不活跃时，增加 $N$ 或 $D$ 都能降低损失，预算约束因而取等号。将其写为
\begin{equation}
 D=\frac{C_{\mathrm b}}{kN+\Delta g(Q)}
 \label{eq:p3_budget_balance}
\end{equation}
即可看出两类竞争：提高 $N$ 会压缩可负担的数据量，提高 $Q$ 也会通过处理成本减少 $D$。最优配置需要在直接收益与这部分间接损失之间取得平衡。

\textbf{3.参数量与数据量的平衡}\par\nopagebreak[4]
为在绝对数量口径下求导，令 $\widetilde A=A(10^9)^\alpha$、$\widetilde B=B(10^9)^\beta$。将式\eqref{eq:p3_budget_balance}代入规模损失项，固定 $Q$ 后得到
\[
 F(N)=\widetilde A N^{-\alpha}
      +\widetilde B\left[\frac{kN+\Delta g(Q)}{C_{\mathrm b}}\right]^\beta.
\]
令 $F'(N)=0$，整理可得
\begin{equation}
 \alpha\widetilde A N^{-\alpha}
 \left(1+\frac{\tau(Q)}{N}\right)
 =\beta\widetilde B D^{-\beta},
 \qquad \tau(Q)=\frac{\Delta g(Q)}k.
 \label{eq:p3_balance}
\end{equation}
$\tau(Q)$ 是把质量处理费用按单位参数训练成本折算的附加规模，与 $N$ 同口径。式\eqref{eq:p3_balance}把质量投入对参数--数据平衡的影响集中在 $1+\tau/N$ 中；因此，付费提升质量后，原有的两类规模项平衡也会改变。

若质量保持在基线，$\tau=0$，则有 $\alpha\widetilde A N^{-\alpha}=\beta\widetilde B D^{-\beta}$。再结合 $kND=C_{\mathrm b}$，在固定上下文条件下得到
\begin{equation}
 N^*\propto C_{\mathrm b}^{\beta/(\alpha+\beta)},\qquad
 D^*\propto C_{\mathrm b}^{\alpha/(\alpha+\beta)}.
 \label{eq:p3_scaling}
\end{equation}
两个指数分别约为 $0.459$ 和 $0.541$，数据量随预算增长略快于参数量。这一关系作为无额外质量投入时的基准；跨越质量提升阶段时，配置应由完整模型确定。

\textbf{4.数值求解与阶段识别}\par\nopagebreak[4]
采用 SLSQP 求解式\eqref{eq:p3_problem}，以 $\ln N$、$\ln D$ 为规模变量，减小数量级差异。三档预算分别使用 8 组初值，预算扫描使用 5 组初值，在求解成功的结果中取损失最低者。下文将这一数值候选解记为 $(N^*,D^*,Q^*)$；多初值不能保证全局最优，且 $\gamma<1$ 时端点 $Q=1$ 的导数不有界，故饱和配置按边界解处理。

为比较不同预算下的质量投入，定义完成度 $\Theta=(Q^*-Q_0)/(1-Q_0)$ 与质量份额 $f_Q=D^*\Delta g(Q^*)/C_{\mathrm b}$。质量处于基线、内部或上界，分别对应 $\Theta=0$、$0<\Theta<1$ 和 $\Theta=1$。在 $10^{18}$--$10^{25}$ FLOPs 范围设置 141 个对数等距预算点，相邻预算比约为 1.122，以有效解中首次出现正质量投入和达到上界的位置识别阶段变化。扫描中 $1.41\times10^{19}$ FLOPs 处求解失败，分析使用其余 140 点。图中标记对应有效记录，跨缺测点的点线仅连接两端，不代表补算结果。

预算增至 $1.78\times10^{19}$ FLOPs 时，首次出现额外质量投入。此后质量完成度与质量份额同步上升，至 $7.08\times10^{19}$ FLOPs，质量达到上界，质量份额也达到扫描峰值 $40.7\%$。前一有效点的质量约为 0.955，因此扫描将饱和边界定位在 $[6.31,7.08]\times10^{19}$ FLOPs 之间；相应的启动边界位于 $[1.58,1.78]\times10^{19}$ FLOPs 之间。这些区间反映当前网格分辨率，不能解释为精确的临界预算。

质量达到上界后，进一步投入无法继续提高 $Q$，预算扩张转而支持参数量和数据量增长。此时 $\Delta g(1)$ 固定，由预算等式可得
\[
 f_Q=\frac{\Delta g(1)}{kN^*+\Delta g(1)}.
\]
随着参数量上升，质量份额自然下降，至 $10^{24}$ FLOPs 时约为 $1.6\%$。这并不要求质量处理的总费用下降：新增 token 仍支付相同处理单价，只是模型训练费用增长得更快。质量饱和的原因是可行上界，而非边际质量收益趋零；后者与问题二估计的 $\gamma<1$ 不符。

\textbf{4.配比收益与结果适用范围}\par\nopagebreak[4]
数据配比研究表明，领域权重可以影响预训练效率\cite{xie2023doremi}。本模型以常数项 $M$ 表示这一影响：在 $10^{22}$ FLOPs 下，采用问题一推荐配比后，配置不变，预测损失从 2.1450 降至 1.9462。现有二分计算给出的参考配比等损失预算约为 $3.05\times10^{23}$ FLOPs，即约 30 倍原预算。这是固定损失平移假设下的算力等价估计，其跨规模含义依赖第二题讨论的迁移条件，不能作为实际训练加速比。

本节得到的主要区别在于：质量水平达到上界以前，增加预算会改变质量与规模的投入组合；达到上界以后，质量处理继续发生，但其预算份额随参数规模增长而下降。低预算选择对质量成本较敏感，长上下文则通过训练单价与可负担数据量共同影响配置。定量使用这些结果还需考虑评分尺度衔接及外推范围，特别是高预算方案所需的数据量。数据受限训练研究指出，重复数据的收益会随重复次数增加而衰减\cite{muennighoff2023scaling}；本文尚未加入语料供给与重复训练约束，高预算配置因而应视为理论情景。
