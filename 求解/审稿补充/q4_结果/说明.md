# 问题四事后诊断

这些文件用于核对已有回归和条件曲线的解释范围，不替换 `问题四/结果` 中的原模型结果，也不构成新训练实验。

## 复现

在任意工作目录运行：

```text
python <仓库>/求解/审稿补充/q4_时间与前沿验证.py --data <real_attachments路径>
```

也可设置 `MODELING_DATA_DIR`，用 `--output` 指定诊断输出目录；`--data-dir`、`--output-dir` 是兼容别名。程序只读 C1、C3 附件及问题四已有结果，核对新版前沿模型与规模配对、两窗口分解及原曲线和点预测。运行前后检查原结果 SHA-256，将输入哈希、软件版本、配对核验与结果哈希写入摘要。

## 表格对应

| 文件 | 正文标签 | 用途 |

| `q4_横截面诊断.csv` | `tab:q4_review_time` | 名称去重、类型控制、年份与连续提交日编码比较 |
| `q4_窗口敏感性.csv` | `tab:q4_review_window` | 保持 logistic 函数、初值和界限，改变锚点、末端窗口或持平点权重 |

| `q4_前沿诊断序列.csv` | 窗口、留出两表 | C3 年度累计峰值与 C1 月度前列均值的组合序列 |
| `q4_诊断摘要.json` | 两张诊断表、统一时间留出表及正文 | 样本数、时间间隔、两个方法起点、前沿规模配对核验、来源与哈希 |

## 解释边界

- 年份组差不是同一个模型随时间增长的速度。连续提交日斜率仅用于编码诊断，也不是更优的因果估计。
- 同名首条、末条按附件原始行序确定。去重不意味着相近命名的模型已全部归并，也不提供独立性保证。
- 删除持平点改变累计前沿信息的权重，不建议据此清理原数据或择优报告更高预测值。
- 留出窗口是看到完整序列后选择的特定平台期。持平参照的零误差不证明其未来普遍优于 logistic；该检查也不是预注册、独立外部验证。
- C3 与 C1 没有完成历史量表校准。原曲线和所有窗口诊断都保留这一限制。
- C3 按累计峰值模型配对参数量，C1 前列组按平均对数参数量核算，长期规模关联项更新为 51.4%。配对改动未改变前沿得分与时间，因此原窗口及时间诊断的数值仍适用。
- 问题四原 CSV 的“贡献”与“bt(分/年)”等历史列名及情景名称为接口兼容保留；正文分别解释为规模关联项、未解释剩余项、年份标签差异和设定年增量。
- 没有重新计算原 bootstrap 结果。论文保留的第 5 至第 95 百分位是既有残差重抽样后曲线重拟合的分位范围，不是未来观测预测区间。
