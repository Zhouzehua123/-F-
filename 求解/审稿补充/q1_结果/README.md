# 问题一补充诊断的使用范围

这些文件是对既有观测、拟合和保存配方的独立复核，不是新增语言模型训练结果。原问题一评分、系数、推荐及跨问质量基线不在本目录中改写。

## 运行

在仓库根目录运行：

```text
python 求解/审稿补充/q1_决策与稳健性.py --data-dir <real_attachments根目录>
```

`--section decision` 只复核决策，`--section quality` 只复核标尺；省略时运行全部诊断。`--output-dir` 可以指定另一独立目录。程序拒绝将输出放入原结果目录或附件目录，并在运行前后比对原 CSV 与 `问题一_关键量.json` 的 SHA256。

## 文件对应关系

| 文件 | 角色与论文位置 |
|---|---|
| `q1_目标一致检验.csv` | 对已有检验配方按正式的 13 域加权目标统计误差、排序和选优；对应第六节 `tab:weighted_decision`，不是连续推荐配方的实测收益。 |
| `q1_线性候选双代理对照.csv` | 读取 `线性有界配比对照.csv`，分别以线性岭和已选核岭评价旧线性方案；对应 `tab:q1_review_surrogates`。 |
| `q1_正则配置敏感性.csv`、`q1_正则条件候选配比.csv` | 只检验原线性模型在四档正则参数下的系数和配方；对应 `tab:q1_review_ridge`，不能解释为核岭推荐的敏感性。 |
| `q1_核岭正式配方核验.json` | 读取 `推荐配比调整.csv` 及训练凸组合证书，复核当前核岭正式配方的约束和固定模型预测；不重跑优化，不证明全局最优。 |
| `q1_A1标尺域均分对照.csv`、`q1_A1标尺权重对照.csv`、`q1_A1标尺诊断.json` | 用 A1 估计填补值、归一化端点、长度中心与权重，再冻结后评价全量文本；对应 `tab:q1_review_calibration`，不替换原评分和后问的质量基线。 |
| `q1_冲突标签定位.csv` | 汇总既有冲突标签在域中位数上下的分布；标签表示相对位置，不能当作人工核验或冲突消解真值。 |
| `q1_复现清单.json` | 记录最近一次调用的运行范围、程序版本、方法源码、输入与输出哈希。分段调用保留另一段已有结果，字段 `section` 标明最近一次调用范围。 |

当前核岭推荐重建为 48 个训练配方的非负凸组合，预测加权损失为 4.644364，参考配方为 4.817338，模型内差值为 −0.172974。算法中保存的 `stationarity_gap` 是对零份额采用数值保护后的梯度间隙，不是边界光滑驻点证书。真实训练效果及跨尺度平移仍应按正文的条件解释。
